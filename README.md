# Movie Explorer

A responsive movie and TV show discovery application built with React and the TVMaze API.

## Features

- Responsive movie and TV show browsing
- Search movies and TV shows by title
- Dynamic search results
- Movie/show cards with:
  - Poster
  - Title
  - Release year
  - Rating
- Detailed movie/show modal
- Genre and summary information
- Missing poster fallback
- Loading and error states
- Responsive layout for mobile and desktop
- React Router navigation
- Debounced API search

## Technologies Used

- React
- JavaScript
- React Router
- Tailwind CSS
- Vite
- TVMaze API

## API

This project uses the free [TVMaze API](https://www.tvmaze.com/api).

Endpoints used:

- `https://api.tvmaze.com/shows`
- `https://api.tvmaze.com/search/shows?q=:query`
