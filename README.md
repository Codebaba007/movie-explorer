# Movie Explorer

A responsive movie and TV show discovery application built with React and the TVMaze API.

## Live Demo

https://movie-explorer-indol-sigma.vercel.app/

## GitHub Repository

https://github.com/Codebaba007/movie-explorer

## Features

- Responsive movie and TV show browsing
- Search movies and TV shows by title
- Dynamic search results
- Debounced search requests
- Movie/show cards with:
  - Poster
  - Title
  - Release year
  - Rating
- Detailed movie/show modal
- Large poster view
- Genre information
- Release date
- Movie/show summary
- Missing poster fallback
- Broken image fallback
- Loading state
- Error state
- Empty search result state
- Responsive layout for mobile and desktop
- React Router navigation

## Technologies Used

- React
- JavaScript
- React Router DOM
- Tailwind CSS
- Vite
- TVMaze API

## API

This project uses the free TVMaze API.

API documentation:

https://www.tvmaze.com/api

### Endpoints Used

Get all shows:

https://api.tvmaze.com/shows

Search shows:

https://api.tvmaze.com/search/shows?q=:query
